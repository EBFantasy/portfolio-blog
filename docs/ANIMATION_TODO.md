> 1. **微交互**（hover/按压/tab 切换/折叠展开等过渡）——开发组件时**当场顺手写**，不进此清单。
> 2. **编排型动画**（滚动叙事、入场编排、首屏特效、页面过渡）——骨架期只在此登记，**动效冲刺期统一实现**，做完一项打个勾。

> 全局约束：所有动画必须尊重 `prefers-reduced-motion`；动效统一走 CSS transition/animation + framer-motion（引入时再定），避免引入 GSAP 之外的重型库。
