爬虫调度和报表流水线看起来是两种页面：前者在 24 个节点之间推进队列，后者依次点亮五个处理阶段。它们却共享同一个工程问题——画面由异步事件推动，而用户随时可能暂停、重跑或重置。状态机因此不仅是几个状态名称，还包括「哪个回调仍有资格修改当前画面」。

## 把画面看成状态的投影

爬虫节点有 `undiscovered`、`queued`、`fetching`、`done`、`blocked` 五种状态；队列、进行中数量和已见节点集合放在 ref 中，React state 保存用于渲染的快照。报表阶段则使用 `pending`、`active`、`done`，配合 `stageIdx` 和进度值驱动界面。

这并不等于两个 Demo 已经统一成单个 reducer，而是提供一个阅读方式：按钮是否可用、节点颜色和日志数量，都应当能从当前轮次的状态解释。只把 `running` 设为 `false`，并不会自动让队列、定时器和已完成回调进入一致状态。

## 清理定时器只是第一层

报表 Demo 把每次运行创建的 timeout 都放进数组，在重新运行、重置和组件卸载时统一清理。这个模式避免了明显的重复推进：

```ts
const timers = useRef<ReturnType<typeof setTimeout>[]>([]);

function clearTimers() {
  timers.current.forEach(clearTimeout);
  timers.current = [];
}

useEffect(() => () => clearTimers(), []);
```

爬虫 Demo 对调度用的 interval 也有类似处理：暂停和重置会清除它，卸载时会再次清理。但每个模拟请求还各有一个独立 timeout。由此可见，「持有一个主定时器引用」不等于所有异步工作都可取消；递归 timeout、请求完成回调和延迟动画都要计入生命周期。

## 暂停与重置需要不同语义

暂停通常只停止派发新任务。当前爬虫暂停后，已经派发的模拟请求仍会完成并写回结果，这可以解释为「暂停调度」，但不能宣传成冻结整个世界。若产品语义要求完全冻结，就需要另行保存剩余时间或延迟完成事件。

重置则更严格：旧一轮的任何回调都不应污染新一轮。当前实现会清掉 interval、队列和计数，却没有给独立请求回调设置轮次标识，因此这里需要补强，而不是声称已经解决。可以给每一轮运行一个代次，回调执行前先核对：

```ts
const generationRef = useRef(0);

function reset() {
  generationRef.current += 1;
  // 再清理 interval、队列、进行中计数与界面状态
}

function scheduleFetch(id: number, ms: number) {
  const generation = generationRef.current;
  setTimeout(() => {
    if (generation !== generationRef.current) return;
    // 只有本轮回调可以更新 activeRef、队列和日志
  }, ms);
}
```

全新一轮运行也要递增代次；从暂停恢复同一轮则不应递增。登记并清除 timeout 有助于释放资源，代次检查保证无法取消的旧回调即使抵达也没有副作用，两者解决的是不同问题。

## 文案必须说清模拟到了哪一步

爬虫没有向真实网站发出请求。站点图是固定的，429 是在激进配置下按概率产生的模拟结果，robots 开关演示的是调度规则。因此准确的表述是「模拟站点上的调度可视化」，而不是「生产级采集器」或「真实网站合规抓取」。

报表同样使用内置文件信息与固定汇总数组。阶段动画展示校验、清洗、去重、合并、汇总的概念，并未读取访客文件，也没有在后台执行真实的数据清洗。浏览器确实会生成并下载一个文件，但「文件真实可下载」不等于「数据经过真实处理」。涉及能力的文案应明确写出内置样例、模拟结果和浏览器端生成，不借一个可点击按钮暗示不存在的后端集成。

## CSV 转义不能省略

当前导出逻辑直接拼接字段，而固定金额含有千分位逗号，例如 `45,620.00`。若不加引号，这个单元格会被表格软件拆成两列；字段中的双引号与换行也有同样问题。下面是应采用的转义方式，并不表示它已经接入现有 Demo：

```ts
const cell = (value: string | number) => {
  const text = String(value);
  return /[",\r\n]/.test(text)
    ? `"${text.replace(/"/g, '""')}"`
    : text;
};

const csv = "\uFEFF" + rows
  .map((row) => row.map(cell).join(","))
  .join("\r\n");
```

含逗号、双引号或换行的字段需要整体加双引号，字段内部的双引号再写成两个。BOM 有助于常见表格软件识别 UTF-8 中文，CRLF 则是更稳妥的 CSV 行尾。金额导出时最好保留 `45620.00` 这种纯数值形式，把千分位留给界面显示。一个小导出函数，同样需要明确的数据边界与状态纪律。
