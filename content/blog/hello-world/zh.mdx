## 技术选型

站点基于 **Next.js 15 + TypeScript + Tailwind CSS v4** 构建，部署目标是 Vercel。选这套组合的理由很直接：

- Next.js 的 App Router 用「文件即路由」组织页面，加板块 = 加目录；
- TypeScript 约束内容元数据和组件接口，写错构建期就报错；
- Tailwind 让样式即类名，视觉统一且改版快。

## 双语是怎么做的

所有页面挂在 `app/[lang]/` 动态段下，内容分 `zh` / `en` 两套字典与文章目录。访问没有语言前缀的路径时，中间件按浏览器语言自动跳转，URL 形如 `/zh/blog/xxx`、`/en/blog/xxx`。

```ts
// middleware.ts 的核心逻辑
const lang = accept.includes("zh") ? "zh" : "en";
return NextResponse.redirect(new URL(`/${lang}${rest}`, req.url));
```
